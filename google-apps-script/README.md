
# 📖 คู่มือการติดตั้ง AI Analyst ใน Google Sheets (Native Google Solution)

เพื่อให้คุณสามารถถามคำถามและให้ AI วิเคราะห์ข้อมูลจาก Google Sheets ได้โดยตรง โดยไม่ต้องผ่าน Server ภายนอก เราจะใช้ **Google Apps Script** ร่วมกับ **Gemini AI** ครับ

---

## 1. ขอ Gemini API Key (ฟรี)
1. เข้าไปที่ [Google AI Studio](https://aistudio.google.com/app/apikey)
2. เข้าสู่ระบบด้วยบัญชี Google ของคุณ
3. คลิกปุ่ม **"Create API key"**
4. คัดลอก API Key เก็บไว้เพื่อใช้ในขั้นตอนถัดไป

---

## 2. วิธีติดตั้งสคริปต์ใน Google Sheets
1. เปิดไฟล์ Google Sheets หลักของคุณ (**Income-Expanses by manus**)
2. ไปที่เมนู **Extensions** (ส่วนขยาย) > **Apps Script**
3. ลบโค้ดเดิมออกให้หมด แล้วนำโค้ดจากไฟล์ `google_apps_script_gemini.js` ที่ผมให้ไว้ไปวางแทนที่
4. นำ API Key ที่ได้จากข้อ 1 มาใส่ในบรรทัดที่ 6: `const GEMINI_API_KEY = "ใส่_API_KEY_ของคุณที่นี่";`
5. กดปุ่ม **Save** (รูปแผ่นดิสก์) และตั้งชื่อโปรเจ็คว่า "AI Financial Analyst"
6. รีเฟรชหน้า Google Sheets ของคุณ

---

## 3. วิธีใช้งาน
1. หลังจากรีเฟรช คุณจะเห็นเมนูใหม่ชื่อ **🤖 AI Analyst** ปรากฏขึ้นข้างๆ เมนู Help
2. คลิกที่ **🤖 AI Analyst** > **ถาม AI**
3. พิมพ์คำถามที่คุณต้องการ เช่น:
   - *"เดือนนี้ทำงานกี่วัน"*
   - *"หนี้ตัวไหนต้องจ่ายก่อน"*
   - *"สรุปรายรับเดือนที่แล้วให้หน่อย"*
4. รอสักครู่ AI จะแสดงคำตอบให้คุณทันทีในหน้าจอครับ!

---

## 💡 ข้อดีของวิธีนี้
- **ปลอดภัย**: ข้อมูลวิ่งอยู่ภายในระบบของ Google เท่านั้น
- **ฟรี**: Gemini API มีโควต้าให้ใช้ฟรีเหลือเฟือสำหรับการใช้งานส่วนตัว
- **Real-time**: ข้อมูลที่ AI เห็นคือข้อมูลล่าสุดในชีตเสมอ
