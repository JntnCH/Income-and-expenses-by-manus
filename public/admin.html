ดู Chat ID ของตัวเองได้ง่ายๆ โดยทักหา @userinfobot ใน Telegram
ขั้นตอนสร้างและเชื่อมต่อบอท 4 สเต็ปง่ายๆ
  1. เปิดแอป Telegram แล้วค้นหาบัญชี @BotFather (มีเครื่องหมายถูกสีฟ้า)
  2. พิมพ์ /newbot แล้วทำตามคำแนะนำ โดยตั้งชื่อบอท และตั้ง username ให้ลงท้ายด้วย bot เช่น my_expense_bot
  3. @BotFather จะส่ง HTTP API token มาให้ ให้คัดลอกมาวางในช่อง Token ด้านบน แล้วกด "บันทึกการเชื่อมต่อ"
  4. กดปุ่ม "ผูก Webhook อัตโนมัติ (1-Click Setup)" เพื่อให้ Telegram ส่งข้อความตรงมายังระบบนี้ จากนั้นกด "เปิดแชทใน Telegram" แล้วเริ่มพิมพ์ใช้งานได้ทันที!
